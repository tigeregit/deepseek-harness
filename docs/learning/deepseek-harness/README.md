## 先建立三句话的认识

模型负责产生文本与工具调用意图；Harness 负责管理输入、上下文、执行、状态和生命周期。Cordis 负责把这些能力按依赖组装成可拆卸的插件系统。Session 日志记录运行事实，其中的部分事实投影为下一次模型请求的历史。

这三个职责贯穿所有章节。后续读到一个包，先判断它属于哪项职责，以及它提供、消费或观察了什么能力。

## 阅读深度

**必读**：1—7 与实操，建立主干认识。**第二轮读**：8—9 与工程化，在知道执行流程后理解扩展选择。**按需求查阅**：UI 详细注册协议、SSH/沙箱实现、持久格式迁移、Typert 类型图、native OS 机制。各类方向都在地图内，具体实现留在其拥有的文档和源码。

实操包含真实 Cordis、ToolRuntime 和 AgentLoop 的无密钥验证；模型输出由脚本适配器提供。它验证接线与生命周期，真实模型选工具的效果需要后续集成实验。
